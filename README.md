# Hotel Website Demos

Five complete, themed demo websites for one fictional pilgrim hotel (Hotel Kesar Palace, 300 m from Mahakaleshwar Temple, Ujjain) — built with Next.js 14 + Tailwind.

- `/` — showcase landing (pick a design)
- `/haveli` Classic Trust · `/jyoti` Modern Animated · `/kesar` Warm Devotional · `/rajwada` Heritage Luxury · `/shanti` Minimal Editorial
- Each theme: Home, About, Rooms & Tariff, Amenities, Gallery, Contact + room-availability WhatsApp booking (native check-in date picker), Hindi/English toggle

**Rebrand for a client:** edit `lib/config.ts` (name, city, phone, WhatsApp, map, tariff images).

```bash
npm install
npm run dev
```
